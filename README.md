## About

I'm a Computer Science undergraduate in Nepal, building full stack applications end to end while I finish my degree.

Most of what I know came from shipping things rather than following tutorials — designing the schema, writing the backend, building the interface, then finding out what I got wrong and fixing it. That loop taught me more about software than any course has.

Right now I'm most interested in the backend side: how data is modeled, how APIs are structured, and how systems stay reliable as they grow. I'm also working with applied machine learning, specifically recommendation systems.

I'm looking for **internships and entry-level software engineering roles**, and I'm open to open source collaboration.

## Projects

### Cosmetic recommendation system

A recommendation engine that suggests products based on user preferences, skin type, and product attributes.

The interesting problem here was the cold start: a new user has no history, so collaborative filtering has nothing to work with. I handled it by leading with content-based similarity over an engineered product feature set, then blending in collaborative signals as interaction data accumulates.

`Python` · `Django` · `Scikit-learn` · `PostgreSQL`

[Repository →](https://github.com/Rhythmmanandhar/cosmetic-recommendation)

### Personal portfolio

A responsive single-page portfolio built as a reusable component system rather than a static page.

The goal was maintainability — adding a new project should mean adding a data entry, not editing markup. Mobile-first layout, lazy-loaded assets, accessible navigation.

`React` · `Tailwind CSS` · `Vite`

[Repository →](https://github.com/Rhythmmanandhar/portfolio)
