<summary><b>Cosmetic Recommendation System</b></summary>

<br/>

An intelligent recommendation engine that suggests cosmetic products based on user preferences, skin type, and product attributes, combining collaborative filtering with content-based similarity scoring.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, Django, Scikit-learn, PostgreSQL |
| **Scale** | Full web application with user accounts and product catalogue |
| **Performance** | Precomputed similarity matrices for low-latency inference |
| **Security** | Session-based authentication, input validation, ORM-level query safety |
| **Impact** | Personalized product discovery that reduces manual browsing effort |
| **Repository** | [View Repository](https://github.com/Rhythmmanandhar/cosmetic-recommendation) |

The system profiles each user against a feature-engineered product catalogue and blends two recommendation strategies: content-based similarity for cold-start users and collaborative signals as interaction history grows. The pipeline covers data cleaning, feature extraction, model training, and serving through a Django backend.
